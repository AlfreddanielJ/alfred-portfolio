## Frontend Development Standards

For all website and UI development:

- Use the `frontend-design` and `ui-ux-pro-max` skills when relevant.
- Before implementation, establish a coherent design system appropriate to the product, audience, and existing tech stack.
- Prefer distinctive, intentional design over generic AI-generated layouts.
- Build responsive, accessible interfaces with consistent typography, spacing, colors, and reusable components.
- Preserve existing project architecture and avoid unnecessary dependencies.
- Run the application and verify important UI behavior and responsive layouts whenever browser tooling is available.
- Never claim visual verification unless the rendered interface was actually inspected.
